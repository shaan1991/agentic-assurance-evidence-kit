# Judgement day checklist

The six artefacts, assembled Monday night, presented Tuesday.

1. Evidence file. Pageable, covering the runs to be scored.
2. Threshold document. Per control: metric, limit, exception tolerance,
   measurement basis, version, date. Dated before any assessed run.
3. Control test tool. The CLI. Judges type the question, the tool answers.
4. Two named runs per control. Timestamps plus run IDs. One satisfied, one
   violated.
5. One page architecture sketch. See docs/architecture-sketch.md.
6. Gap list. What is missing or thin, stated plainly. Honesty scores.

The live test: a judge names one control and one window. Answer from the
tool, with the records behind it, in under two minutes. Inside the 10 minute
presentation, keep the demo to two minutes and let the tool do the talking.
